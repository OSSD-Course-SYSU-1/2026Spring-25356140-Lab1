# 播放功能快速测试脚本

## 测试前准备

### 1. 确保设备连接
```bash
hdc list targets
```

### 2. 编译项目
```bash
hvigorw assembleHap
```

### 3. 安装应用
```bash
hdc install entry-default-signed.hap
```

## 测试步骤

### 步骤1：清空日志并启动应用
```bash
# 清空日志
hdc hilog -r

# 启动应用
hdc shell aa start -a EntryAbility -b com.example.wyy_music
```

### 步骤2：查看初始化日志
```bash
hdc hilog | grep -E "IndexPage|PlayerService|AVPlayer"
```

**预期输出**：
```
IndexPage: Initializing player...
Creating AVPlayer...
AVPlayer created, setting up listeners...
AVPlayer initialized successfully
IndexPage: Player initialized
IndexPage: Playlist initialized
```

### 步骤3：点击播放按钮
在应用中：
1. 进入"我的"标签页
2. 点击"播放测试歌曲"按钮

### 步骤4：查看播放日志
```bash
hdc hilog | grep -E "Button|playSong|Playing"
```

**预期输出**：
```
Button clicked: Play test song
Test song: 起风了 买辣椒也用券
Play URL: https://www.soundhelix.com/examples/mp3/SoundHelix-Song-1.mp3
playSong called, song: 起风了 URL: https://...
Player already initialized
Resetting player...
Setting play URL...
Preparing player...
Starting playback...
✅ Playing song: 起风了
AVPlayer state changed to: playing
```

### 步骤5：验证播放效果
检查以下内容：
- [ ] 底部出现迷你播放栏
- [ ] 显示歌曲名称"起风了"
- [ ] 显示歌手"买辣椒也用券"
- [ ] 播放进度条开始移动
- [ ] 可以听到音频播放

## 一键测试脚本

### Windows (PowerShell)
```powershell
# test_player.ps1
Write-Host "=== 播放功能测试 ===" -ForegroundColor Green

Write-Host "`n[1/5] 清空日志..." -ForegroundColor Yellow
hdc hilog -r

Write-Host "`n[2/5] 启动应用..." -ForegroundColor Yellow
hdc shell aa start -a EntryAbility -b com.example.wyy_music

Write-Host "`n[3/5] 等待初始化..." -ForegroundColor Yellow
Start-Sleep -Seconds 3

Write-Host "`n[4/5] 查看初始化日志:" -ForegroundColor Yellow
hdc hilog | Select-String -Pattern "IndexPage|PlayerService|AVPlayer" | Select-Object -First 10

Write-Host "`n[5/5] 请在应用中点击'播放测试歌曲'按钮，然后按任意键继续..." -ForegroundColor Cyan
$null = $Host.UI.RawUI.ReadKey("NoEcho,IncludeKeyDown")

Write-Host "`n查看播放日志:" -ForegroundColor Yellow
hdc hilog | Select-String -Pattern "Button|playSong|Playing" | Select-Object -First 15

Write-Host "`n=== 测试完成 ===" -ForegroundColor Green
```

### Linux/Mac (Bash)
```bash
#!/bin/bash
# test_player.sh

echo "=== 播放功能测试 ==="
echo ""

echo "[1/5] 清空日志..."
hdc hilog -r

echo ""
echo "[2/5] 启动应用..."
hdc shell aa start -a EntryAbility -b com.example.wyy_music

echo ""
echo "[3/5] 等待初始化..."
sleep 3

echo ""
echo "[4/5] 查看初始化日志:"
hdc hilog | grep -E "IndexPage|PlayerService|AVPlayer" | head -10

echo ""
echo "[5/5] 请在应用中点击'播放测试歌曲'按钮，然后按回车继续..."
read

echo ""
echo "查看播放日志:"
hdc hilog | grep -E "Button|playSong|Playing" | head -15

echo ""
echo "=== 测试完成 ==="
```

## 故障排查

### 问题：初始化失败
```bash
# 查看详细错误
hdc hilog | grep "Failed to create AVPlayer"
```

### 问题：播放失败
```bash
# 查看详细错误
hdc hilog | grep "Failed to play song"
```

### 问题：网络错误
```bash
# 测试音频URL
curl -I https://www.soundhelix.com/examples/mp3/SoundHelix-Song-1.mp3
```

### 问题：权限错误
```bash
# 查看应用权限
hdc shell dumpsys permission com.example.wyy_music
```

## 日志分析工具

### 提取关键日志
```bash
# 提取所有播放相关日志
hdc hilog | grep -E "Player|Song|AVPlayer|playSong" > player_log.txt

# 分析错误
grep -E "ERROR|Failed|❌" player_log.txt

# 分析成功步骤
grep -E "✅|successfully|complete" player_log.txt
```

### 实时监控
```bash
# 实时监控播放状态
watch -n 1 'hdc hilog | grep -E "AVPlayer state|Playing" | tail -5'
```
