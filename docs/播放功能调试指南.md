## 常见问题排查

### 问题1：AVPlayer创建失败
**日志**：
```
Failed to create AVPlayer: {"code":xxx,"message":"..."}
```

**可能原因**：
- 设备不支持AVPlayer API
- HarmonyOS版本过低
- 系统资源不足

**解决方案**：
- 检查设备HarmonyOS版本（需要API 9+）
- 重启设备
- 检查系统日志

### 问题2：网络连接失败
**日志**：
```
AVPlayer state changed to: error
AVPlayer state: ERROR
```

**可能原因**：
- 网络连接问题
- 音频URL无法访问
- 网络权限问题

**解决方案**：
- 检查设备网络连接
- 验证音频URL可访问
- 检查module.json5中的INTERNET权限

### 问题3：音频URL无效
**日志**：
```
Invalid song URL
```

**解决方案**：
- 检查TestData.ets中的音频URL
- 使用可访问的测试音频URL

### 问题4：状态监听未触发
**日志**：
```
Playback started - waiting for state change callback
```
但没有后续的 `AVPlayer state changed to: playing` 日志

**可能原因**：
- AVPlayer状态变化监听未正确设置
- 异步操作问题

**解决方案**：
- 检查setupPlayerListeners是否正确调用
- 检查AVPlayer.on('stateChange')回调

## 如果仍然无法播放

### 1. 检查网络权限
确保 `entry/src/main/module.json5` 中有以下权限：
```json
"requestPermissions": [
  {
    "name": "ohos.permission.INTERNET"
  }
]
```

### 2. 检查网络配置
确保设备可以访问互联网。

### 3. 检查AVPlayer API支持
确认设备支持AVPlayer API。

### 4. 创建最小测试用例
创建一个简单的测试页面，只测试AVPlayer的基本功能：
```typescript
// 测试AVPlayer基本功能
async testAVPlayer() {
  try {
    const avPlayer = await media.createAVPlayer();
    console.info('AVPlayer created successfully');
    
    avPlayer.url = 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-1.mp3';
    await avPlayer.prepare();
    await avPlayer.play();
    console.info('AVPlayer playing');
  } catch (error) {
    console.error('AVPlayer test failed:', error);
  }
}
```
