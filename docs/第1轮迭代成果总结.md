## 一、创建的文件清单

### 1. 数据模型层（2个文件）

#### `entry/src/main/ets/common/bean/SongInfo.ets`
**用途**：歌曲信息数据模型  
**内容**：
- 歌曲ID、标题、艺术家、专辑名称
- 封面图片URL、音频文件URL
- 歌词内容、歌曲时长

#### `entry/src/main/ets/common/bean/PlayerState.ets`
**用途**：播放器状态枚举  
**内容**：
- `PlayState`：播放状态（IDLE、PLAYING、PAUSED、STOPPED、ERROR）
- `PlayMode`：播放模式（LIST_LOOP、SINGLE_LOOP、RANDOM）

### 2. 服务层（1个文件）

#### `entry/src/main/ets/common/service/PlayerService.ets`
**用途**：播放器服务（单例模式）  
**核心功能**：
- ✅ AVPlayer音频播放管理
- ✅ 播放列表管理（设置、添加、移除）
- ✅ 播放控制（播放、暂停、停止、上一首、下一首）
- ✅ 进度控制（跳转、获取当前时间/总时长）
- ✅ 播放模式切换（列表循环、单曲循环、随机播放）
- ✅ 状态监听回调（播放状态、时间更新、歌曲变化）

### 3. UI组件层（2个文件）

#### `entry/src/main/ets/view/MiniPlayer.ets`
**用途**：底部迷你播放栏组件  
**UI元素**：
- 歌曲封面（小图）
- 歌曲标题和艺术家
- 播放/暂停按钮
- 下一首按钮
- 进度条（迷你版）

**交互**：
- 点击整个迷你播放栏 → 跳转到完整播放器页面
- 点击播放/暂停按钮 → 控制播放状态
- 点击下一首按钮 → 播放下一首歌曲

#### `entry/src/main/ets/pages/PlayerPage.ets`
**用途**：完整播放器页面  
**UI元素**：
- 歌曲封面（大图）
- 歌曲标题和艺术家
- 播放进度条（可拖动）
- 播放控制按钮（上一首、播放/暂停、下一首）
- 播放模式切换按钮
- 返回按钮

**交互**：
- 点击返回按钮 → 返回上一页
- 拖动进度条 → 跳转播放位置
- 点击控制按钮 → 执行对应操作

### 4. 测试数据层（1个文件）

#### `entry/src/main/ets/common/constants/TestData.ets`

**内容**：

- 包含完整的歌曲信息（标题、艺术家、封面等）

## 四、技术实现要点

### 1. 音频播放
- 使用HarmonyOS AVPlayer API
- 支持在线音频URL播放
- 实现播放状态监听和错误处理

### 2. 状态管理
- 使用单例模式管理播放器状态
- 使用@State装饰器实现UI响应式更新
- 使用回调函数实现跨组件状态同步

### 3. UI设计
- 遵循HarmonyOS设计规范
- 使用Flex和Column布局
- 使用Unicode符号作为图标（临时方案）

### 4. 路由管理
- 使用router.pushUrl()进行页面跳转
- 在main_pages.json中注册页面路由

## 五、使用指南

### 快速开始
1. 启动应用
2. 进入"我的"标签页
3. 点击"播放测试歌曲"按钮
4. 底部出现迷你播放栏，显示当前播放歌曲

### 完整播放器
1. 点击底部迷你播放栏
2. 进入完整播放器页面
3. 可进行所有播放控制操作

### 播放控制
- **播放/暂停**：点击中间的控制按钮
- **上一首/下一首**：点击左右两侧的控制按钮
- **进度跳转**：拖动进度条滑块
- **播放模式**：点击播放模式按钮切换
